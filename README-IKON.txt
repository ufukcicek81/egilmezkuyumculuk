EĞİLMEZ KUYUMCULUK - PWA İKON DÜZELTMESİ

- Müşteri uygulaması adı: Eğilmez
- Admin uygulaması adı: Eğilmez Admin
- Müşteri ve admin için ayrı, kare PWA ikonları oluşturuldu.
- Eski ikon dosya adları kullanılmadı; böylece Android/Chrome eski ikonu cache'den çekmez.
- Web arayüzündeki varsayılan Eğilmez logosunun sağındaki istenmeyen parça temizlendi.

ÖNEMLİ:
Telefonunda daha önce kurulu Eğilmez/Admin uygulamasını kaldırıp yeni sürümü tekrar kur.
Android, kurulu PWA'nın eski başlık ve ikonunu otomatik değiştirmeyebilir.

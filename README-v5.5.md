# Eğilmez Kuyumculuk Premium v5.5 – Açılış Ekranı

Bu sürüm v5.4 üzerinden hazırlanmıştır.

- Android/PWA açılışında görünen büyük kare ikon yerine koyu premium ikon kullanılır.
- Müşteri uygulamasında yükleme sırasında tema tercihine uygun özel açılış ekranı gösterilir.
- Açılış logosu çerçevesizdir; altında küçük “Güvenin Altın Değeri” metni ve zarif yükleme çizgisi bulunur.
- Admin uygulamasının açılışı da ayrı “EĞİLMEZ ADMIN” ekranıyla düzenlenmiştir.
- Manifest ve ikon dosya adları v3 olarak değiştirildiği için eski PWA ikon önbelleğinin kullanılma ihtimali azaltılmıştır.

GitHub'a paketteki tüm dosyaları yükleyin. Telefonda önceden kurulu Eğilmez ve Eğilmez Admin uygulamalarını kaldırıp yeniden kurun; Android eski kurulu PWA'nın manifest/ikonunu saklayabilir.

# Eğilmez Kuyumculuk – Premium v3

- Bağımsız Firebase: egilmez-kuyumculuk-default-rtdb.europe-west1.firebasedatabase.app
- Müşteri ekranı: index.html
- Yönetim uygulaması: admin.html
- Koyu / yumuşak açık tema
- Müşteri ve TV ekranında detaylı Döviz Kurları / Hurda Altın bölümü gösterilmez.
- Döviz ve hurda düzenleme alanları yalnızca yönetici ekranında kalır.
- Varlıklarım kayıtları cihaz bazında Eğilmez'e özel localStorage alanında tutulur.
